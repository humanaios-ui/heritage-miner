# Smallest verified research path

1. **Private source custody:** keep raw GEDCOM, memoir scans, proof receipts and living-person details off GitHub.
2. **Start with one dispute:** identify exact source record ID, asserted fact, and competing historical publication or civil record.
3. **Reproduce externally:** independently read the named public source; preserve page, publication date, and retrieval source.
4. **Test the Witness:** run the disagreement comparison. Require immutable original observations, distinct source identity, no selected historical fact and no authority effect.
5. **Resource Miner proposal:** one opaque non-executable research action targeting the nearest primary record.
6. **Human decision:** decide whether to request a public archive record. No automatic outreach, purchasing, eligibility determination or GEDCOM edit.
7. **Measure:** track source-identification success, source count after deduplication, false promotions, conflict persistence and time per verified claim.

## Explicit limits
The prototype does not reconcile exact identities across databases, automatically verify documents, resolve the Mayflower line, prove Cherokee or other citizenship/entitlements, or ingest raw private records into public code repositories.

## First-stage baseline
No repository-level claim discrepancy engine existed. Added synthetic tests check fail-closed behavior; success means code correctly preserves contradictory assertions, not that genealogical claims have been settled.
